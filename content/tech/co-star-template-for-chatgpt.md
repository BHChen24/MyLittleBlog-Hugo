> 🔔 **Prelude:**
> If you use ChatGPT frequently, you've probably encountered situations where it provides off-topic answers. Since we can't modify the model, the better approach is to rely on accurate prompts and additional context.

## 🖋️ Main

#### **Let ChatGPT Answer Your Questions Accurately!**

First, you need to let ChatGPT know some personal information about you and how it should respond to you.

1. Click on your profile picture at the top right corner.
2. Select "Customize ChatGPT."
3. Hover over the "Custom Instructions" question mark on the right and fill in the information as guided.
4. Use the specific CO-STAR template in a new session.
5. Interact with ChatGPT.

---

#### CO-STAR Template

The CO-STAR template is a structured method that can help you communicate more clearly and effectively with ChatGPT. By providing context, objectives, style, tone, audience, and response format, you can explain exactly what you need from ChatGPT, and get replies that correspond more closely with your requirements.

```
# CO-STAR Template

## Template Example

# Context
# I am a university student majoring in computer science, writing a paper on the application of machine learning in financial analysis.
# Objective
# Please help me write a section about the advantages and challenges of machine learning in stock market prediction.
# Style
# The style should be academic, using formal and technical language.
# Tone
# The tone should be serious and professional, avoiding humor or overly casual expressions.
# Audience
# The target audience is researchers and professionals in finance and computer science who are familiar with the relevant terminology and concepts.
# Response
# Please provide the content in paragraph form, including clear arguments and supporting evidence.
```

You can simply copy and paste this template to use it! Or, here is a more detailed explanation:

```
## Context
# Provide relevant background information to help the model understand the current situation.

## Objective
# Clearly state your goal or the task you want ChatGPT to help you with.

## Style
# Specify the desired writing style, such as formal, informal, technical, etc.

## Tone
# Define the desired tone, such as persuasive, humorous, serious, etc.

## Audience
# Define the target audience so the model can adjust the complexity and terminology of its output.

## Response
# Specify the desired response format, such as a list, paragraph, or a specific data format.
```
